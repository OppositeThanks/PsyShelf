DEMO - Working Memory
Original educational sample prepared for a PsyShelf user walkthrough.
2026-10-02 | Language: English | Topic: Cognitive psychology

CONCEPT
Working memory supports holding and manipulating information during an ongoing task. It is useful when following instructions, calculating mentally, or keeping track of the beginning of a sentence while reading its end.

EXAMPLE
To calculate 27 plus 18 mentally, a reader holds the numbers while combining tens and units. Interruptions can make this task harder because attention is shared.

KEY DISTINCTION
Maintaining information briefly and using it actively are related but distinct functions. Working memory is not an unlimited store of everything a person knows.

READING QUESTION
What information must be maintained, and what operation must be performed on it?
