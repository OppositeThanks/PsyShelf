# PsyShelf improvement checklist

Created 2026-09-10. Unchecked = to do; checked = completed and verified.
When an item is finished, change `[ ]` to `[x]` and add its completion date.
This is a planning note, not a list of features already available.

## First priorities

- [ ] **Backup restoration and history** — Restore a saved backup, retain previous versions, and show the last successful backup.
- [ ] **Background imports and backups** — Keep the app responsive during large file operations, with progress and cancellation.
- [ ] **In-app updates** — Notify users of new GitHub releases and let them choose when to install.

## Library efficiency

- [ ] **Faster search** — Use indexed database search and load results in batches for large libraries.
- [ ] **Duplicate detection** — Flag existing files or links and offer to update their entries.
- [ ] **Missing-file repair** — Reconnect moved or renamed files while keeping their metadata and notes.

## Useful additions

- [ ] **Reading status and collections** — Add To read, Reading, and Finished, plus saved collections.
- [ ] **Bulk editing** — Edit categories, languages, or reading status for multiple resources together.
- [ ] **Search inside documents** — Find passages with page references; add text recognition for scanned PDFs.
- [ ] **Source-linked AI answers** — Link answers to supporting passages and pages in the library.
- [ ] **Citation export** — Copy references and export bibliographic data for research and writing.
